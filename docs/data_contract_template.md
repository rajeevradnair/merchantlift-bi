# Data Contract Template

## Purpose

This document defines the standard data contract template for MerchantLift BI.

Every fact table, dimension table, staging table, intermediate model, and mart should eventually have a contract based on this template.

A data contract defines:

- what the table represents
- what one row means
- which columns are required
- which values are allowed
- which quality checks apply
- which privacy classifications apply
- who owns the table
- which downstream assets depend on it
